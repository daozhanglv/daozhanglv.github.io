## 确认你在哪里

操作之前，先确认当前目录。再查看目录下的文件，避免把相对路径理解错。

```bash
pwd
ls -lah
```

## 查找文件和内容

如果已经安装 ripgrep，可以用 `rg` 搜索文本，或用 `rg --files` 列出文件。

```bash
rg --files
rg -n 'timeout' ./logs
```

给搜索范围加上目录，通常比直接搜索整个磁盘更有效。

## 看看资源状态

磁盘空间和进程信息是常见的排查入口。

```bash
df -h
ps aux
```

先收集信息，再决定如何处理。把命令输出、执行时间和环境一起记录，方便之后复现。
